# Support

> **In short**
>
> - WebAIAssist is a small open-source project run by one person. Answers take days, not hours.
> - For a bug, open a GitHub issue with the Chrome version, the extension version, the model and the site. Copy diagnostics in the panel gives most of it.
> - For a question or an idea, use GitHub Discussions.
> - For a security problem, use the repository's Security tab and do not open a public issue.
> - There is no e-mail address for support. Do not post API keys or page text you would not want public.
