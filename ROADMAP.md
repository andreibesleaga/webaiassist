# Roadmap

> **In short**
>
> - These are candidates for later releases. They are not promises, they have no dates, and something here may never be built.
> - Candidates include reading more of what sites publish, a live meter of the model's context, more interface languages (English today) and a model file you choose.
> - Also listed: re-measure every model path after each Chrome and model update, and check Edge and Brave.

These are candidates for later releases. They are not promises and they have no dates. Something
here may never be built. What a release contains is in [CHANGELOG.md](CHANGELOG.md).

## Reading more of what sites publish

- A list of the skills index a node publishes.
- Show the provenance of `llms.txt`, and let the model read one chosen section of `llms-full.txt`.
- Read the page's own HTTP `Link` header, including the FAIR Signposting relations.
- Show a site's sustainability file with its signature checked (today it only says "signed").

## The panel

- Tools of frames on the same site.
- A live meter of how much of the model's context is used.
- A chat in a full tab.
- A passphrase vault for API keys.
- More interface languages (English only today).

## Models

- Bring your own model file, chosen with a local file picker. Never a typed address.
- Re-measure every model path after each Chrome and model update (see [docs/EVAL.md](docs/EVAL.md)).

## Browsers

- Check Edge and Brave and record what works.

## Not planned

- Web search, tools across tabs, frames of other sites, access to all sites at once, saved
  recordings of a whole chat to play back, voice, a 3D graph. A bridge that lets other programs use the panel's tools: maybe later,
  maybe never.

To suggest something, open an issue or a discussion: see [SUPPORT.md](SUPPORT.md).
