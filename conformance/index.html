WebMCP conformance page

This page tests the WebMCP interface of your browser. It sends nothing anywhere, holds no analytics and needs no account. It is independent of any browser extension.

WebMCP lets a page offer tools, such as “add this to the cart”, to an AI assistant through document.modelContext. Each case below registers some tools and checks one part of the interface: registering and removing tools, listing and running them, the hints a tool can carry, input schemas, errors, cancelling, slow and large results, forms that become tools, tools that appear or vanish later, and a few tools that try to mislead an assistant. Open a case with its link to see only its tools, or use all cases at once (more than 200 tools).

This browser has no document.modelContext. In Chrome 157, start it with --enable-features=WebMCP or switch on the flag chrome://flags/#enable-webmcp-testing, then reload.
