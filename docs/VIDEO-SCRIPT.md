# Demo video script

Length: under 3 minutes. Screen: Chrome at 1280 × 800, a clean profile, no personal tabs or
bookmarks. The extension is installed from the release zip; the model was downloaded once
before recording, and the first Start is shown from a second, fresh profile (or cut short).

| Time      | Screen                                                                                                                                                               | Voice (read as written)                                                                                                         |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 0:00–0:15 | The Chrome Web Store page (or `chrome://extensions` with **Load unpacked**)                                                                                          | "WebAIAssist is a chat in the side panel with an AI model that runs on your own computer."                                      |
| 0:15–0:35 | Click the toolbar button; the panel opens and names the model it picked and why. Press **Start**, then **Download**; the progress bar fills.                         | "Press Start once. It shows what it will download and from where, and waits for me. The model stays in the browser."            |
| 0:35–0:55 | Open an AgenticSystemCore node page. The card reads "says it is an AgenticSystemCore node, 10 WebMCP tools", and lists them.                                         | "This page offers ten tools through WebMCP, a draft web standard. The panel lists them, and what the site publishes."           |
| 0:55–1:20 | Type "Find items about review" and press Ctrl+Enter. The question "Use the tools of …?" appears; press **Allow for this session**.                                   | "The first time, it asks whether it may use this site's tools at all."                                                          |
| 1:20–1:45 | The question "Run the tool search?" with the site and the arguments. Press **Allow once**. The result appears, marked as untrusted page content; the answer follows. | "Before each call I see the tool, the site and the exact arguments. The result is marked as page content, not as instructions." |
| 1:45–2:10 | Ask "Propose the first one as my next task". The gate asks for `propose`; press **Deny**. The transcript says it was denied.                                         | "A tool that changes something always asks. I can say no."                                                                      |
| 2:10–2:30 | Open a page without WebMCP; press **Read this page**; ask "Summarise this page".                                                                                     | "On any other page, Read this page gives the model the text."                                                                   |
| 2:30–2:50 | The Options page, then the README's Privacy section.                                                                                                                 | "Your questions, the page and the results stay on this computer. Other runtimes, like Ollama, are in Options."                  |
| 2:50–3:00 | The icon and the repository link.                                                                                                                                    | "WebAIAssist. Open source, Apache 2.0."                                                                                         |

Shot list: (1) install, (2) Start and progress, (3) node page with the tool count, (4) site
question, (5) tool question with arguments, (6) result marked untrusted and the answer,
(7) Deny on `propose`, (8) Read this page, (9) Options, (10) closing card.
